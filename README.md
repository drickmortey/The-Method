# What's this?
This is a Luau course I work on sometimes, meant to give you a foundation strong enough to do everything else on your own. Learn the language
and some of the baggage that comes with computer science. All of this has been meticulously written to include as much detail as I can add.

I express spite for online tutorials for being shallow and ambiguous, not answering
many underlying questions. It takes time and will to become good enough, become independent.
AKA escaping a known phenomenon called "tutorial hell" (if you know you know).
I myself started with youtube tutorials, it was sickening at best. Having knowledge yet not being
able to make anything at all, or anything I would personally want. This required much enlightening to cure.

So if you too would like to become an enlightened spirit, you can start right now. The course primarily covers Luau as a language, API isn't touched on a lot. (*Edit: Planned API section added*)
But we'll keep enough contact with Roblox Studio in order to not lose the plot.

Feedback from anybody genuinely trying to learn, or from an experienced scripter checking if their bases are right, is very much appreciated. Improvements help everybody. Unfortunately there are not many tasks, if you could tell me what confused you the most I could design a task for that in the respective article (which will come with a hint section like every other task to guide you). Some things in the earlier articles may become inconsistent due to edits in the later ones, or due to human error in typing, so please let me know if you encounter this.

This is all human-made and fact checking has been done wherever possible and feasible. But people can make mistakes, so excuse me. If something should be taken with a grain of salt, I'll follow it up with an asterisk `*`.
